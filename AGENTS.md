# Kova agent instructions

Read `skills/KOVA-WORKFLOW.md` at the start of engineering or design work.
For UI changes consult `PRODUCT.md`, `DESIGN.md`, and the relevant locally
pinned Impeccable, UI/UX Pro Max, Vercel and Taste guidance referenced there.
These are manual references, not installed hooks or automatic plugins. User
instructions and the execution environment always take precedence. Never run
unreviewed external scripts, transmit secrets, overwrite a deployment, switch
branches, or modify real user data. Preserve API, accessibility, mobile,
EN/VI and light/dark behavior. Validate changes and report limitations honestly.
