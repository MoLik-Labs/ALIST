# Kova interface direction

**Mode:** operate. The workspace is an everyday tool, not a marketing site.

Use a quiet, legible workspace with a clearly differentiated navigation rail,
workspace canvas and content surfaces. Keep familiar side navigation, path
breadcrumbs, file lists and standard controls. Cobalt identifies navigation,
selection and primary actions; status colors carry meaning, never decoration.
A fine active-navigation edge and a restrained contextual path header provide
the signature across explorer and administration without hiding functionality.

Use system fonts, clear type hierarchy, generous targets where touch is likely,
precise borders instead of expensive decoration, and tabular numbers for file
metadata. Maintain consistent geometry and contrast in light, dark and system
themes. Show focus, loading, empty and error states; support reduced motion and
long or untrusted names. All interface features and authorization boundaries
must continue to work as before. A complete redesign requires real-browser and
mobile-device review; DOM tests alone do not establish visual quality.
